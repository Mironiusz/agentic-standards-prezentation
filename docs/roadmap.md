# Plan prac

Pracujemy fazami: jedna faza to jedna rozmowa. Po każdej fazie prelegent ogląda slajdy
w przeglądarce i zgłasza poprawki, zanim ruszy następna.

| Faza | Zakres                                                                                       | Status         |
| ---- | -------------------------------------------------------------------------------------------- | -------------- |
| 0    | Silnik: reveal.js, kroki GSAP, motyw, mapa etapów, zrzuty, PDF-y, próba z zegarem, Kahoot    | gotowe (D-013) |
| 1    | Plan treści w `SEED.md` i opis w `docs/overview.md`                                          | gotowe (D-016) |
| 2    | 41 slajdów według planu i poprawki prelegenta                                                | gotowe         |
| 3    | Wersja docelowa: bez dopisków roboczych, Kahoot, materiały do ćwiczenia, plansza wyników     | gotowe (D-016) |
| 4    | Standardy formatowania i jakości kodu z quantaska: prettier, kontrola stylu (`npm run lint`) | gotowe (D-017) |

## Otwarte sprawy

- Prelegent przepisuje zdania na slajdach i w notatkach po swojemu.
- Próba z zegarem i test na rzutniku według `docs/pokaz.md`, potem poprawki czasów w `src/slides/timing.js`.
